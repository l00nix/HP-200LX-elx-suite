# ELX tools package 0.2.0

This packaging release contains ELXstat 0.1, ELXbat 0.1.3, ELXctl 0.1 and
ELXdash 0.1.1 for the HP 200LX running firmware-aware ELKS. Individual application
source and versions are unchanged.

- Removed the old Commander and screen-capture source trees, guides and previews
  from the current suite. They are maintained in ELKS-Cmdr and ELKS-scrcap.
- Added a root native build, explicit seven-file install manifest, EPT recipe,
  8.3 installed-name checks and EPT instructions.
- Includes the project GPL and separate font license.
- No DOS program, kernel, startup changes or charging configuration is included.

All host tests, native i8086/memory audits, selected native emulator checks and an
isolated ELKS/QEMU EPT install/hash/version/remove test passed. Exact rebuilt HP
hardware acceptance remains pending; the automated checks do not imply it.

The package is HP-specific. Generic PC users should use the standalone Cmdr and
scrcap packages instead of attempting HP hardware-control operations.
