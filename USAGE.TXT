ELX tools package 0.2.1 - HP 200LX only, running firmware-aware ELKS

Included: elxstat 0.1, elxbat 0.1.4, elxctl 0.1, elxdash 0.2.0-test4.
Includes the newer gauge redraws and Battery menu from the HP 4.0 bundle.
Cmdr and scrcap are separate projects/packages and are NOT bundled here.

Commands:
  elxstat             read firmware/system status
  elxstat battery     battery and external-power status
  elxbat              main/backup voltage gauges on the local HP console
  elxbat --text       text battery report
  elxctl status       read hardware settings
  elxctl --dry-run contrast 16   preview a change without applying it
  elxdash             interactive gauges and hardware controls
  elxdash --demo      synthetic demonstration, local console only
Use each program's --help for details.

Dashboard: Tab selects; Left/Right or -/+ adjusts; R rereads; Q/Esc exits.
Controls: contrast, volume, text zoom, annunciators and firmware timeout.
Firmware timeout is not the ELKS sleep policy. Installing or opening the
dashboard does not change battery chemistry or enable charging. Press B for
the Battery menu; Up/Down/Tab select, Left/Right edit limits, Enter chooses,
Esc closes. Start is locked unless --charge-test is explicitly supplied.
Experimental NiCd tests also require confirmation; no full-charge profile or
physical charging validation is claimed. The supervisor survives dashboard
exit; reopen B and select Stop test to stop it. Never use with other cell types.
See the online guide before opting in. Battery volts are cached BIOS values,
not remaining-charge percentages. Firmware warning flags are separate from
the nominal threshold triangles. LCD/keyboard tests on exact builds remain
separate from host/emulator tests; consult the repository's testing record.

Requires genuine supported HP firmware, readable /dev/kmem (normally root),
and an HP firmware-aware ELKS kernel. Graphics tools require the local text
console. Do not run hardware controls on a generic PC or the Amstrad PPC.
EPT installation only copies files: no kernel, startup or battery changes.

EPT: add REPO=http://ept.8088retro.com to /etc/ept.cfg without deleting your
existing repositories, then: ept update; ept install elxtools
Remove this package with: ept remove elxtools
