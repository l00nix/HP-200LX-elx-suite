# Preview provenance

These are interim software previews, not physical-device screenshots of the
current builds. Replace with labelled hardware captures after testing, while
keeping versions and capture conditions explicit.

| Image | Source |
| --- | --- |
| ELXdash | 0.1.1 shared renderer in demo mode; synthetic values |
| ELXbat | 0.1.3 renderer, offline synthetic firmware snapshot |
| ELXstat | Actual 0.1 offline-fixture text output, typeset as a terminal image |
| ELXctl | Actual 0.1 simulation output, typeset as a terminal image |

The dashboard and ELXbat PNGs are vertically doubled from their 640×200 pixel
buffers to show the intended HP LCD aspect ratio. Text outputs used for the two
terminal previews are retained here. No HP ROM/font dump is distributed.

`power-states.png`: actual ELXbat 0.1.3 status-strip rendering with synthetic
battery, external, enabled/inactive, charging, fast charging, unplugged and
read-failure states. Not a physical HP capture.
