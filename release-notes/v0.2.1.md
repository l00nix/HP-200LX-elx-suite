# ELX tools 0.2.1 — current dashboard and battery display

Updates the four-tool package to **ELXbat 0.1.4** and **ELXdash 0.2.0-test4**
from the published HP 200LX 4.0 application sources. ELXstat and ELXctl stay at 0.1.
Version 0.2.0 inadvertently packaged older dashboard/battery snapshots.

- Incremental gauge and status redraws, including steady unchanged polling.
- Battery menu with Up/Down/Tab selection, editable limits and stable dialogs.
- Experimental native NiCd test supervisor, locked by default. Start requires
  --charge-test and explicit NiCd confirmation; installation never starts it.
- Same seven EPT-owned paths. Cmdr, scrcap and DOS LXdash remain separate.

Use `ept update` then `ept install elxtools` with the
[8088retro mirror](http://ept.8088retro.com) configured. Existing EPT 0.2.0
installations upgrade through the same package name. Preserve manually installed
builds before replacing them.

See [testing status](https://github.com/l00nix/HP-200LX-elx-suite/blob/main/docs/TESTING.md).
Host/emulator checks are separate from physical HP graphics/control acceptance;
no physical charging acceptance is claimed for the ELKS supervisor.
