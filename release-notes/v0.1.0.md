# ELX suite 0.1.0 — initial prerelease

The first suite release brings together the HP 200LX ELKS utilities and the
DOS dashboard companion. Individual tool versions remain independent.

| Tool | Version |
| --- | --- |
| ELXstat | 0.1 |
| ELXbat | 0.1.2 |
| ELXctl | 0.1 |
| ELX Commander | 0.1 |
| ELXcap | 0.1 |
| ELXdash / LXdash | 0.1 |

Start with **ELX-Suite-0.1.0-binaries.zip** for all current executables.
ELKS binaries and DOS/LXDASH.EXE are separated inside it. Source is available
in the repository and source archive. The individual packages include build
and validation evidence; the Dashboard Pack includes ELXbat 0.1.2 and both
dashboards. SHA256SUMS covers release assets.

Highlights:

- Battery gauges with nominal low/critical triangles and separate BIOS flags.
- Interactive dashboard controls with read-back and text zoom queued for exit.
- Command-line status/controls, two-panel file manager and lossless captures.
- Per-tool usage guides, SVG key icons and clearly labelled interim previews.

**Hardware testing pending for current builds.** Host/native emulator tests and
static checks passed; DOS EXE checks use mocked DOS/HP services. Preview images
are not current-build hardware screenshots. The original ELXstat/ELXbat 0.1 were
observed running on the user's HP.

BIOS timeout does not configure ELKS auto-sleep. ELXcap's optional Alt+period
hotkey needs kernel integration; ordinary and delayed capture do not. No boot
kernel, CF image or startup configuration is installed by these packages.
